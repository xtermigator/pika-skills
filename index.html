Inclusive Game Day

A non-commercial open-source accessibility project for invisible disabilities and sensory needs.

Non-Commercial  ·  Public Interest  ·  Open Source

Inclusive Game Day is a free, non-commercial, open-source public-interest accessibility project focused on improving inclusion, predictability, and support for people with invisible disabilities, sensory needs, chronic illness, neurodivergence, anxiety, and other conditions that can make participation in public experiences more difficult. No paywalls. No ads. No data collection. Just practical resources that support inclusion and access.

What this project supports

  • Inclusion — everyone deserves meaningful access and participation
  • Predictability — clear structure and low-surprise formats that reduce overwhelm
  • Sensory needs — guidance on lighting, sound, texture, scent, and pacing
  • Invisible disabilities — resources that don't require visible proof of need
  • Flexible participation — options for different energy levels, communication styles, and processing speeds

This project is open source and maintained as a public-interest accessibility resource. View the source, contribute, or adapt it freely on GitHub. Licensed under the MIT License.
